# 선발/심사 통합 관리 — 기획 정적 화면

As-Is 에서 유지보수 업체가 SQL 로 돌리던 선발·심사 업무를 tdwfadmindev 관리자 화면 안으로 옮겼을 때의 모습을 보여 주는 기획용 퍼블리싱입니다.
서버 없이 `index.html` 을 브라우저로 열면 됩니다.

- 화면 모양: tdwfadmindev 의 실제 CSS(`css/admin.css`, `css/base/*.css`)와 Pretendard 폰트를 그대로 복사해 썼습니다. 기획에만 필요한 스타일은 `css/plan.css` 에 따로 두었습니다.
- 데이터: 화면 동작용 인물정보는 마스킹된 예시입니다. **2024년 건강검진사업의 지역별 정원·신청 건수(17개 지역 × 본인·배우자)는 공고 설정과 접수 집계값을 반영**했습니다.
- 상단 우측 메모 아이콘: 주황색 **기획 메모**를 숨기거나 다시 보이게 합니다. 고객 시연 때는 숨기면 됩니다.
- 선발기준설정과 1차심사의 **공고조회**: tdwfadmindev 공통 공고조회 팝업과 같은 검색조건·목록으로 공고를 선택합니다. 선발기준설정은 단계 막대 없이 공고 정보와 모집인원만 보여 줍니다.

## 기획상 결정 사항 / 확인 필요

- **병원변경 위치**: 변경요청서(10/15)에 따라 사업사후관리 기능을 심사관리로 옮기므로 병원변경을 **후속심사**에 두었습니다. 현재 개발본은 건강검진은 실적관리, 예방접종은 신청내역 팝업에 있어 옮기는 작업이 필요합니다.
- **모든 일괄처리는 "미리보기 → 확정" 2단계**이고 확정 내역은 일괄처리 이력에 남습니다(As-Is 는 SQL 직접 실행이라 흔적이 없었음).
- **현업 확인 필요**: 부부 신청에서 한 명만 검진한 경우, 검진한 사람의 지급을 그대로 진행하는지.
- 추가선발은 정원에서 이미 선발된 인원을 빼고 뽑습니다. 현재 개발본의 선발확정 재실행은 차감 없이 정원 전체를 다시 뽑아 초과 선발될 수 있습니다.

## 파일 구성

```
index.html      화면 골격(헤더/GNB/LNB, 각 화면, 팝업)
app.js          사업별 예시 데이터와 화면 동작
css/plan.css    기획 메모·미리보기 등 기획 전용 스타일 (실제 개발 시 옮기지 않음)
css/admin.css, css/base/   tdwfadmindev 원본 CSS 복사본
fonts/, assets/            원본 폰트·로고 복사본
```
