    Home chevron_forward 심사관리 chevron_forward 최종선발
    lightbulb
    As-Is 「최종선발.sql」 「1차선발.sql」: 관리자 화면에서 결재정보를 등록할 수 없어 APPROVE_STAT='03' 결재 행을 SQL 로 넣고, 04 → 05 전환, 사용자 노출 상태, 공고 상태(60), 지급이력 생성까지 쿼리 다섯 번을 차례로 돌렸습니다.
    • 결재정보를 화면에서 등록합니다. 실제 결재선은 2018년부터 쓰지 않으므로 「즉시 결재완료」를 기본으로 둡니다.
    • 발표는 사용자 화면에 무엇이 어떻게 보이는지 미리 보여 준 다음 확정합니다. 발표 전에는 사용자가 결과를 알 수 없어야 합니다.

    대상자 문자발송 신규

    Homechevron_forward심사관리chevron_forward대상자 문자발송
    lightbulb
    As-Is 는 문자 대상자를 매번 SQL 로 뽑아 발송 큐에 직접 넣었습니다(「검진상태_문자안내」 「선발인원_문자발송」 「안내문자_접수준비」 등 8개 파일). To-Be 문자발송은 번호 직접 입력·엑셀 업로드뿐이라 조건으로 대상을 뽑을 수 없습니다.
    • 심사 단계의 상태·지역·병원으로 대상을 뽑고, As-Is 쿼리가 하던 제외 규칙을 옵션으로 둡니다.
    • 부부가 둘 다 미검진이면 운전자에게만, 부부가 같은 번호를 쓰면 한 번만 보냅니다.
    • 대량 발송은 As-Is 처럼 날짜별로 나눠 예약합니다.
